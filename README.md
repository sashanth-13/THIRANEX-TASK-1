Project Title: Titanic Data Cleaning & Exploratory Data Analysis (EDA)
Overview
This project focuses on the foundational skills of data science: cleaning, processing, and visualizing raw data. Using the famous Titanic dataset, this project demonstrates how to handle incomplete and messy data to uncover meaningful insights about passenger survival rates.

Key Objectives

Data Cleaning: Identify and remove exact row duplicates to ensure data integrity.

Missing Value Imputation: Handle missing data strategically by dropping unusable columns (e.g., deck) and filling missing numerical and categorical values using statistical measures like median and mode.

Outlier Handling: Use percentile capping to manage extreme outliers in ticket fares, preventing them from skewing visual distributions.

Exploratory Data Analysis (EDA): Build clean, easy-to-understand visualizations to answer specific questions about passenger demographics and survival trends.

Tools & Libraries Used

Python: The core programming language.

Pandas & NumPy: Used for data manipulation, cleaning, and mathematical operations.

Matplotlib & Seaborn: Used for generating static, high-quality data visualizations.

Key Visualizations & Insights

Survival by Class: A bar chart analyzing how a passenger's socioeconomic status (1st, 2nd, or 3rd class) impacted their chances of survival.

Age Distribution: A histogram mapping the general age demographic of the passengers on board.

Fare vs. Age: A scatter plot colored by survival status to identify clusters and relationships between age, ticket cost, and survival.
